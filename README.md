# Block Blast Pygame

A Python implementation of the popular mobile game **Block Blast** using the `pygame` library.

## Features
- **8x8 Grid**: Classic block puzzle grid.
- **Drag and Drop**: Intuitive mouse controls to place blocks.
- **Line Clearing**: Clear rows and columns to score points.
- **Combo System**: Bonus points for clearing multiple lines.
- **Game Over Detection**: Automatically detects when no more moves are possible.

## How to Play
1. **Run the game**: `python3 main.py`
2. **Drag blocks**: Use your mouse to drag the three blocks from the bottom onto the grid.
3. **Clear lines**: Fill an entire row or column to clear it and gain points.
4. **Don't get stuck**: The game ends when you can no longer place any of the available blocks.
5. **Restart**: Press `R` to restart after a game over.

## Requirements
- Python 3.x
- Pygame (`pip install pygame`)

## Installation
```bash
git clone https://github.com/liqthr/block-blast-pygame.git
cd block-blast-pygame
pip install pygame
python3 main.py
```
